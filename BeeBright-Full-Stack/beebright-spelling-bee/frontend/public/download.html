🐝 BeeBright on your laptop

Latest BeeBright Local release

All three 2027 Bee levels and twelve racing tracks. No login or cloud progress. Practice offline using your computer’s voice.

Windows

Run this in PowerShell (Windows x64):

irm https://beebright.app/install.ps1 | iex

macOS or Linux

Run this in Terminal:

curl -fsSL https://beebright.app/install.sh | sh

After installation, open a new terminal and type beebright. Windows opens the desktop app; macOS and Linux open offline practice in your browser. Keep that terminal open while practicing.

Updates install published releases from beebright-local and preserve your progress. Run beebright update to update or beebright --version to check your installed version. The older beebright.vercel.app install commands also continue to work.
